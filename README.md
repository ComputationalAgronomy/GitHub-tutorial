# GitHub-tutorial
Sandbox for learning GitHub as a team

## Beginner practice tasks

Use this repository to practice the full GitHub flow: issue creation, branch work, pull requests, and reviews.

### How to use these tasks
1. Pick one task from the list below.
2. Open an issue using one of the issue templates in this repository.
3. Create a branch and complete the task.
4. Open a pull request with the PR template.
5. Request at least one review and address feedback.

### Non-programming tasks
- **Improve wording:** Fix typos or unclear sentences in `README.md`.
- **Add a FAQ section:** Add 3 beginner questions and short answers to `README.md`.
- **Write a contribution note:** Create `CONTRIBUTING.md` with a short list of contribution steps.

### Programming tasks
- **Add a simple script:** Create a script (any language) that prints `Hello GitHub Tutorial`.
- **Add input handling:** Update the script to accept a name and print a personalized message.
- **Add basic tests:** Add a small test that verifies the output.

### Review checklist for beginners
- Does the PR clearly explain what changed?
- Does the PR link to its related issue?
- Are file names and structure easy to follow?
- Are there any typos or formatting issues?
- Does the change fully solve the issue task?
